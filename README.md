# -C30-

## 项目简介

`-C30-` 是一个针对 iClass 智慧学习系统的自动化刷课脚本，核心脚本文件为 `刷课.sh`。
该脚本可模拟 Android 移动端设备环境，通过伪装设备指纹、随机 UA 和缓存 Token 来自动登录并执行课程刷新操作。

## 主要功能

- 自动登录 iClass 平台并缓存 `Token`
- 随机生成 Android 设备信息和浏览器 UA
- 获取并验证用户会话信息
- 可发起多线程刷课行为，支持学习状态自动处理
- 彩色终端输出，让脚本状态更直观

## 适用范围

- 仅供学习、研究与脚本分析参考
- 请遵守平台规则与当地法律法规，不建议用于违规操作

## 使用方法

1. 将 `刷课.sh` 下载到 Android 设备或 Linux 终端环境
2. 确保设备已安装 `curl`
3. 赋予执行权限（可选）:
   ```bash
   chmod +x 刷课.sh
   ```
4. 运行脚本:
   ```bash
   sh 刷课.sh
   ```
